# Zdrowy Domowy Smak

Potrzebuję stronę internetową do sprzedaży moich domowych wyrobów. Kombucha, ocet jabłkowy, chleb na zakwasie, mięso z królika. W przyszłości pasztet z królika, kury, jaja od kurek z wolnego wybiegu. Oliwa z oliwek z Włoch. Dla osób, które chcą się zdrowo odżywiać.
